# График работы — переключатель «Неделя/День» рядом с поиском

## 0. Статус: реализовано (2026-09-01)

## 1. Задача

В разделе «Сотрудники → График работы» переключатель «Неделя/День» стоял
отдельной строкой над строкой поиска — занимал лишнюю строку по высоте.
Владелец попросил расположить переключатель справа от поля поиска в одной
строке, сузив поле поиска, — и в мобильной, и в десктопной версии.

## 2. Изменения

- **`src/components/admin/sections/WorkScheduleSection.jsx`** — для
  командного вида (`viewTeam === true`, когда показывается и поиск, и
  таблица сотрудников) `ScheduleViewModeToggle` теперь передаётся как
  `actions` в уже существующий `PlatformSearchToolbar` (тот же приём, что
  используется в «Сотрудниках»/«Ведомости» для кнопки фильтра — раскладка
  `.platform-search-toolbar` уже была flex: поиск `flex: 1 1 auto` тянется/
  сужается, `__actions` `flex-shrink: 0` стоит справа фиксированной
  ширины). Для собственного графика сотрудника (`viewTeam === false`, поиска
  нет) переключатель остался отдельной строкой — заворачивать его не во что.
- **`src/components/admin/ScheduleViewModeToggle.css`** — нижний отступ
  (`margin: 0 0 0.65rem`), который был нужен только для одиночной строки,
  убран из базового класса `.schedule-view-toggle` (иначе внутри
  `.platform-search-toolbar__actions` он бы сбивал вертикальное
  выравнивание с полем поиска) и перенесён в новый класс-обёртку
  `.schedule-view-toggle-standalone`, применяемый только в ветке
  «без поиска».

Отдельного мобильного CSS не потребовалось — `.platform-search-toolbar`
уже одинаково работает на любой ширине (используется по всей платформе),
переключатель просто занимает фиксированную ширину справа и не переносится.

## 3. Verify

```bash
npm run verify:schedule-day-timeline
npm run build
```

Браузерный mount-тест (временный роут `/dev-sandbox-employees`, удалён
после проверки) — `PlatformSearchToolbar` с `ScheduleViewModeToggle` в
`actions` на десктопной ширине, в узком (360px) контейнере и в эмуляции
мобильного вьюпорта (375×812): во всех трёх поиск сужается, переключатель
остаётся справа фиксированной ширины без переноса строки; клик по «День»
переключает активное состояние без ошибок в консоли. Отдельно проверена
раскладка «без поиска» (`schedule-view-toggle-standalone`) — переключатель
остаётся на своей строке с прежним отступом снизу.
