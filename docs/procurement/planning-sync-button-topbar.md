# Планирование — кнопка ручной синхронизации переехала в топбар

## 0. Статус: реализовано (2026-09-02)

## 1. Задача

Владелец попросил перенести кнопку ручной синхронизации UMAG (↻) из строки
поиска в самый правый верхний угол страницы «Планирование» — туда же, где
уже стоит строка `UMAG · дата · SKU · Без поставщика 125` и значок «?»
(подсказка по ABC-колонкам). Освободившееся в строке поиска место отдаётся
самому полю поиска.

## 2. Изменения

- **`src/components/procurement/ProcurementPlannerView.jsx`** —
  `PlatformSyncButton` (обёрнутый в `PlatformToolbarActionWrap` + свой
  `.proc-planner__tip-wrap` для тултипа) убран из `actions` внутри
  `PlatformSearchToolbar` и добавлен последним элементом в `headerStrip`
  (тот же `div.proc-planner__topbar`, который через `createPortal`
  встаёт в `.procurement-page__tabs-aside` — правый верхний угол рядом
  с вкладками «Планирование/Заказы/Нормы/ABC/Склад»). `.proc-planner__topbar`
  уже был `display: flex; justify-content: flex-end` — кнопка, добавленная
  последней, встаёт в самую правую точку сама, без новой раскладки.
  Поле поиска расширяется автоматически: `PlatformSearchToolbar` уже
  устроен как `flex` (`__search` — `flex: 1 1 auto`, `__actions` —
  `flex-shrink: 0`), так что убранный из `actions` элемент просто
  освобождает ширину для инпута — новой CSS для этого не потребовалось.
- **`ProcurementPlannerView.css`** — добавлен модификатор
  `.proc-planner__tip-wrap--topbar[data-tooltip]::after` (`top: calc(100% + 6px)`
  вместо `bottom: calc(100% + 6px)`): в новой позиции, у самого верха
  страницы, тултип, открывающийся ВВЕРХ, упирался бы в шапку платформы —
  модификатор разворачивает его вниз. Базовый класс (тултипы кнопок
  «Создать заказ»/экспорта в строке поиска) не тронут.

## 3. Не тронуто

- Сама логика `handleSync()`/`syncProcurementPlanning()` — не менялась,
  только расположение кнопки, которая её вызывает.
- Кнопки «Только к заказу», выбор поставщика, «Создать заказ», экспорт,
  настройки колонок — остались на своих местах в строке поиска.

## 4. Verify

```bash
npm run verify:procurement-sync-button-topbar
npm run build
```

10/10 проверок: кнопка синхронизации — последний элемент топбара (после
чипов и «?»), в строке поиска её больше нет (остальные actions на месте),
модификатор тултипа существует и переопределяет направление, базовый
тултип-класс не тронут.

Браузерный mount-тест (изолированный рендер `.proc-planner__topbar` с теми
же CSS-классами, временный роут `/dev-sandbox-employees`, удалён после
проверки) — кнопка стоит в правом верхнем углу сразу после «?», при наведении
тултип открывается вниз без обрезки, ошибок в консоли нет.
