# Этап 4 — страница документа

`/platform/procurement/documents/:id` (список этапа 3 теперь открывает документы здесь).

- Шапка «Заказ №N» / «Новый заказ», автор, статус простым серым курсивом, «Добавить комментарий» → небольшое окно.
- Кнопки: черновик — «Сохранить» (присваивает номер; проверка: поставщик, есть товары, количество > 0), «Закрыть», справа «Удалить» (с подтверждением) и «Скачать ▾»; сохранённый — «Закрыть», «Отменить» (→ черновик, номер остаётся), «Скачать».
- Карточки: дата заказа, поставщик (вкладки «Сегодня · N»/«Все», поиск; блокируется, когда есть товары), ожидаемая доставка (русская дата поверх нативного поля).
- Любая правка пишется сразу (количество — при выходе из поля), без полной перезагрузки: обновляется только этот заказ в кэше.
- Таблица позиций с итогом; строка добавления: поиск по названию / штрихкод по номенклатуре снимка UMAG; первый товар задаёт поставщика пустого документа. Кнопки «Товары поставщика» и «Добавить из номенклатуры» появятся на этапах 5–6.
