# Этап 3 — список документов «Закуп»

Новая страница `/platform/procurement/documents` (в меню пока не стоит — подключается на этапе 8).

- Колонки: Номер, Создан, Поставщик, Доставка, Позиций, Сумма, Создал, Комментарий; итог «Итого по списку»; пагинация.
- Период по дате создания, по умолчанию «Неделя»; чип «С … по …» с × (× расширяет до трёх месяцев).
- Фильтр: период, «Название, штрихкод или номер» (название/штрихкод ищет сервер по `purchase_order_items`), поставщики, статус.
- Черновики всегда сверху и не отсекаются периодом (черновик прошлого месяца не должен пропасть); серые курсивом, «Без номера». Статус — линия под суммой: серая у черновика, зелёная у сохранённого. Без плашек, чекбоксов и меню «Действие».
- «＋ Создать» создаёт пустой черновик (без поставщика) и открывает его; до этапа 4 — в старой карточке `/platform/orders/:id`.
- Логика отбора вынесена в `src/utils/purchaseDocumentsList.js` (проверяется реальным модулем).
