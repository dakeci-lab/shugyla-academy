# «Закуп» как документы — архитектура (черновик, 2026-10-29)

Статус: **проект, код не менялся.** Ждёт изучения раздела «Приёмка / Возврат» в UMAG (`web.umag.kz/store/0/supplies`) и одобрения владельца.
Принцип владельца: список документов → кнопка «+» → инструмент создания документа. Тот же порядок, что в UMAG.

## Решения владельца (2026-10-29)
1. Сегодняшняя таблица планирования становится **инструментом внутри документа** («Подбор по плану»), а не стартовым экраном «Закупа».
2. «Склад» — отдельная вкладка раздела «Закупки», после «Расчётов».
3. **Приёмщик** видит только раздел «Заказы»: список сохранённых документов, без отмены и удаления, с галочками по строкам и отметкой «Сверено».
4. **Закупщик** работает в разделе «Закуп»: список документов, создание («+»), правка, сохранение, отмена, удаление. Статусы — «Черновик» / «Сохранён» (этап 25).

## Предлагаемая карта экранов
| Раздел меню «Закупки» | Кто | Что открывается |
|---|---|---|
| Закуп | закупщик (`procurement.view`) | **список документов**: дата, поставщик, доставка, товаров, сумма, статус, создал; фильтр по периоду и статусу; кнопка «+ Создать» |
| (документ) `/platform/procurement/:id` | закупщик | карточка документа: шапка (поставщик, дата доставки, комментарий), таблица товаров, панель «Подбор по плану», «Сохранить» / «Отменить» / «Удалить» / «Скачать» |
| Заказы | приёмщик (`receiving.view`) | список сохранённых документов → документ только для чтения с галочками |
| Расчёты | как сейчас | без изменений |
| Склад | закупщик | вкладка «Склад» (остатки), перенесена из «Закупа» |

## Подбор по плану (бывшее «Планирование»)
Внутри документа: выбрать поставщика → таблица рекомендаций (остаток, продажи/день, цель, в пути, рекомендация, «Заказ») → «Добавить в документ». Дата доставки, запас в днях и «пропускаем визит» (этап 23) остаются в этом инструменте.
Синхронизация UMAG («Обновить данные») остаётся в списке документов или в инструменте — уточнить по макету.

## Как устроено в UMAG («Закупки → Приёмка», фото экранов 2026-10-29)
Меню «Закупки»: Приёмка · Возвраты поставщикам · Платежи.

**Список «Список приёмок»**
- Панель: зелёная «+ Приёмка», «+ Быстрая приёмка» (только сумма, без товаров), «Фильтр ▾», «Действие ▾» со счётчиком выбранных (массовые действия), «Печать ▾», чип периода «С … по …» с крестиком (по умолчанию текущая неделя).
- Колонки: галочка, Номер, Дата (с временем), Поставщик, Счёт, Сумма (под суммой цветная полоска — оплачено/нет), Оплачено, Осталось, Сумма по закупочной, Сумма по продажной, Комментарий, шестерёнка (настройка колонок), карандаш «открыть» в каждой строке.
- Черновики — серым курсивом, номер не ссылкой. Внизу: страницы «1-50 / 115», размер страницы, строка итогов.
- Фильтр (окно): Дата создания (Вчера / Сегодня / Неделя / Месяц / Три месяца + «с … по …»), Код продукта/название, Статус приёмки, Статус оплаты, Тип (создатель — выбор пользователя), Поставщик, Дата изменения (те же быстрые периоды), «Очистить» / «Применить».

**Документ в черновике (редактирование)**
- Заголовок: «Приёмка №… | автор | Черновик». Кнопки слева: зелёная «Провести», «Сохранить как черновик», «Закрыть»; справа: «Добавить комментарий», красная «Удалить приёмку», «Экспорт ▾».
- Карточки шапки: «Дата приёмки *» (дата-время с календарём), «Поставщик *» (выпадающий поиск + карандаш) и рядом «+ Товары поставщика», «Настройки приёмки» («Привязка к поставщику»).
- Вкладки «Товары (N)» / «Бонусы (N)». Над таблицей: «Действие ▾» (для отмеченных строк), «Фильтр», «Поиск по таблице».
- Таблица: №, Название, Штрихкод, Кол-во, Тек. ост. на складе, Ед. изм, цены/наценка/скидка, Итого, «Отскан.», «QR», шестерёнка (колонки), × удалить строку. Внизу строка «Добавление товара» (поиск по названию / штрихкод), кнопки «Добавить из номенклатуры», «+ Создать товар», «+ Создать артикул», «Импорт товаров»; итоги по колонкам.
- «+ Товары поставщика» и «Добавить из номенклатуры» — окна выбора: фильтры (поставщик, поиск, категория, тип), таблица с галочками (название, штрихкод, поставщик, цены), «Добавить», «Посмотреть выбранные N», страницы.

**Проведённый документ (только просмотр)**
- Заголовок «… | автор | Проведён». Кнопки: «Закрыть», красная «Отменить приёмку» (вернуть в черновик), «Экспорт ▾», «Добавить комментарий». Поля шапки не редактируются; блоки «Итоги по платежам» и «Количество товаров по ед. изм.»; вкладки Товары / Бонусы / Платежи; таблица без правки.

## Как это ложится на «Закуп» (предложение)
| UMAG | Наш «Закуп» |
|---|---|
| Список приёмок, чип периода, фильтр, итоги, пагинация | список документов «Закуп»: №, дата, поставщик, доставка, товаров, сумма, статус, создал, комментарий; период по умолчанию — неделя; фильтр как в UMAG |
| «+ Приёмка» | «+ Создать» → пустой документ (поставщик, дата доставки обязательны) |
| «Провести» / «Сохранить как черновик» | «Сохранить» (→ «Сохранён») / «Сохранить как черновик» |
| «Удалить приёмку» (черновик) | «Удалить» (только черновик) |
| «Отменить приёмку» (проведённый) | «Отменить» (→ черновик) |
| «+ Товары поставщика» / «Добавить из номенклатуры» | «Подбор по плану»: окно с товарами поставщика и рекомендациями (остаток, продажи/день, в пути, рекомендация, «Заказ»), «Добавить», «Посмотреть выбранные» |
| Таблица документа с «Действие ▾», фильтром, поиском, настройкой колонок | то же, колонки: №, Название, Штрихкод, Остаток, Продажи/день, Заказать, Закупочная цена, Сумма |
| «Экспорт ▾» | «Скачать» PDF / Excel (как сейчас) |
| Список приёмщика | «Заказы» — тот же список без «+», без «Действие», без карандаша; документ только для чтения с галочками и «Сверено» |

## Отличия, которые нужно решить
1. **Сохранение черновика:** сейчас каждая правка пишется сразу. В UMAG — явная кнопка «Сохранить как черновик». Вариант А: оставить автосохранение (проще, ничего не теряется). Вариант Б: как в UMAG — правки в окне, сохранение по кнопке, предупреждение при выходе.
2. **Номер документа:** в UMAG у каждой приёмки номер. У наших заказов номеров нет (убраны раньше, `remove_purchase_numbers`). Нужен сквозной номер (№1001…), чтобы называть заказ по телефону?
3. **Норматив / «цель, дн» / цвета статусов плана:** владелец предлагает вынести отдельно или временно убрать. Предложение: из таблицы документа и из «Подбора по плану» убрать колонки и цвета «цель / статус плана», сам расчёт рекомендации оставить (иначе подбор бесполезен).
4. **«Быстрая приёмка» (только сумма без товаров):** не переносить.

## Этапы реализации (после одобрения)
1. Список документов «Закуп» + «+ Создать» (создаёт черновик и открывает карточку).
2. Карточка документа: шапка и таблица товаров в стиле UMAG.
3. «Подбор по плану» внутри документа (перенос планирования).
4. Вкладка «Склад» в меню «Закупки» после «Расчётов»; перенос маршрутов, права, подписи меню.
5. Список «Заказы» для приёмщика приводится к одному виду со списком закупщика (только чтение).
Один PR = одно направление; `verify:*` на каждый этап; документ этапа с откатом.
