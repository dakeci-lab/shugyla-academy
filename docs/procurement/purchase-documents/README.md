# «Закуп» как документы — архитектура (черновик, 2026-10-29)

Статус: **проект, код не менялся.** Ждёт изучения раздела «Приёмка / Возврат» в UMAG (`web.umag.kz/store/0/supplies`) и одобрения владельца.
Принцип владельца: список документов → кнопка «+» → инструмент создания документа. Тот же порядок, что в UMAG.

## Решения владельца (2026-10-29)
1. Сегодняшняя таблица планирования становится **инструментом внутри документа** («Подбор по плану»), а не стартовым экраном «Закупа».
2. «Склад» — отдельная вкладка раздела «Закупки», после «Расчётов».
3. **Приёмщик** видит только раздел «Заказы»: список сохранённых документов, без отмены и удаления, с галочками по строкам и отметкой «Сверено».
4. **Закупщик** работает в разделе «Закуп»: список документов, создание («+»), правка, сохранение, отмена, удаление. Статусы — «Черновик» / «Сохранён» (этап 25).

## Предлагаемая карта экранов
| Раздел меню «Закупки» | Кто | Что открывается |
|---|---|---|
| Закуп | закупщик (`procurement.view`) | **список документов**: дата, поставщик, доставка, товаров, сумма, статус, создал; фильтр по периоду и статусу; кнопка «+ Создать» |
| (документ) `/platform/procurement/:id` | закупщик | карточка документа: шапка (поставщик, дата доставки, комментарий), таблица товаров, панель «Подбор по плану», «Сохранить» / «Отменить» / «Удалить» / «Скачать» |
| Заказы | приёмщик (`receiving.view`) | список сохранённых документов → документ только для чтения с галочками |
| Расчёты | как сейчас | без изменений |
| Склад | закупщик | вкладка «Склад» (остатки), перенесена из «Закупа» |

## Подбор по плану (бывшее «Планирование»)
Внутри документа: выбрать поставщика → таблица рекомендаций (остаток, продажи/день, цель, в пути, рекомендация, «Заказ») → «Добавить в документ». Дата доставки, запас в днях и «пропускаем визит» (этап 23) остаются в этом инструменте.
Синхронизация UMAG («Обновить данные») остаётся в списке документов или в инструменте — уточнить по макету.

## Что зависит от UMAG (будет уточнено)
Порядок и названия колонок списка, поведение «+», расположение кнопок документа, различие «сохранить» / «провести», раздел «Возврат».

## Этапы реализации (после одобрения)
1. Список документов «Закуп» + «+ Создать» (создаёт черновик и открывает карточку).
2. Карточка документа: шапка и таблица товаров в стиле UMAG.
3. «Подбор по плану» внутри документа (перенос планирования).
4. Вкладка «Склад» в меню «Закупки» после «Расчётов»; перенос маршрутов, права, подписи меню.
5. Список «Заказы» для приёмщика приводится к одному виду со списком закупщика (только чтение).
Один PR = одно направление; `verify:*` на каждый этап; документ этапа с откатом.
