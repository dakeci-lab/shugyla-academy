# Этап 6 — окно «Добавить из номенклатуры»

Кнопка в строке добавления документа (одна; штрихкод добавляется по Enter).

- Та же таблица, что в «Товарах поставщика» (`CatalogTable`), но по всей номенклатуре платформы — последний снимок UMAG (~8,6 тыс. SKU: товары с остатком или продажами за 8 недель; полный каталог UMAG 27,7 тыс. — возможный отдельный этап).
- Группы свёрнуты и грузят строки при раскрытии (счётчики — из `fetchSnapshotFilterOptions`); поиск от 2 символов идёт на сервер (до 200 строк), группы раскрыты.
- Если у документа есть поставщик — товары других поставщиков недоступны; если нет — первый отмеченный фиксирует поставщика, остальные сужаются до него. Документ без поставщика получает его при добавлении (нужна привязка поставщика у товара).
- «Добавить в документ (N)» — одним запросом.
