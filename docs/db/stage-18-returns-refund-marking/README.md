# Этап 18 — отметка «Возврат получен» у возвратов поставщикам

**Зачем.** В UMAG возврат закрывается сразу при оформлении (`payed_amount = amount` у 208 из 209), поэтому по нему
нельзя понять, вернул ли поставщик деньги. Вводим собственную отметку в платформе — как `platform_paid_at` у накладных.
Накладные (деньги уходят) и возвраты (деньги приходят) ведутся раздельно, взаимозачёта нет.

**Что делает миграция** `20261022120000_supply_returns_native_refund_marking.sql`:
- колонки `platform_refunded_at / _by / platform_refund_account_id` в `umag_supply_returns`;
- все существующие возвраты помечаются полученными от директора (`academy_users.id = 1`), датой самого возврата;
- клиентам разрешено менять только эти 3 колонки (column-level grant) и только с правом `supplier_payments.manage`.

**Порядок.** `preflight.sql` → применить миграцию (MCP, вручную) → `postcheck.sql`. Откат — `rollback.sql`.
UI появится в PR 2 (история операций в карточке поставщика); до него колонки нигде в коде не читаются.
