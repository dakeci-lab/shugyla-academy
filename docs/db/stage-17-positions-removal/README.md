# Этап 17 — удаление должностей и групп должностей

Решение владельца (2026-10-17): остаётся только роль; она же заменяет должность. Платформа — узкий MVP для закупа и
взаиморасчётов, отдельные названия должностей не нужны.

## Что удаляется

- Таблицы `positions` (12 строк, используются 3) и `position_groups` (9), 8 функций `position_structure_*`.
- Колонки `academy_users.position` и `academy_users.position_id` (+ индекс, внешний ключ).
- Права `positions.view`, `positions.manage` (были только у директора).

## Порядок (две фазы, чтобы можно было откатить)

1. **Фаза A — код** (PR этапа 17): фронтенд без должностей (форма, список, вкладки «Должности»/«Группы»), Edge Functions
   `admin-create-employee`, `admin-update-employee`, `admin-list-employees` без работы с должностями (устаревшие поля
   `position*` от старых клиентов игнорируются). Колонка `position` имеет `default ''`, поэтому вставка без неё работает.
   Деплой: слияние в `main`, затем деплой трёх функций.
2. **Фаза B — база** (`preflight.sql` → `apply_17_drop_positions.sql`): после деплоя фазы A и того, как открытые вкладки
   обновились (иначе старый клиент запрашивает удалённые колонки и вход вернёт ошибку до перезагрузки страницы).

## Откат

Фаза A: вернуть предыдущий коммит и функции. Фаза B необратима для данных, но они не нужны (3 пользователя, должность =
роль); при необходимости структуру можно воссоздать по миграциям `20260*_position_*`.
