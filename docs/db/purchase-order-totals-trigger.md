# Итоги заказа считает база

Миграция `20261029160000_purchase_order_totals_trigger.sql` (применена на prod 2026-10-29): три триггера уровня оператора на `purchase_order_items` (insert / update / delete) пересчитывают `purchase_orders.total_amount` и `items_count`.

Проверка (откатываемый тест в SQL Editor): вставка двух позиций → 250 / 2; изменение количества → 350; удаление всех → 0 / 0.

Клиент больше не читает позиции и не записывает итоги после добавления / изменения / удаления строки (экономит 2 запроса на каждое действие и не оставляет устаревших итогов при обрыве связи). Откат: удалить три триггера и функцию `purchase_order_items_recalc_totals`, вернуть вызовы `recalcOrderTotals` в `purchaseSupabaseAdapter.js`.
