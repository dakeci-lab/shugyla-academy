# Этап 22 — отметка «Сверено приёмщиком» на заказе

**Зачем.** Приёмщик сверяет товар с накладной по строкам (галочки в карточке заказа живут в его браузере), а когда всё сошлось — отмечает
заказ целиком. В списке заказов такая отметка видна всем, кто смотрит заказы, и не теряется при смене устройства.

**Что делает миграция** `20261023120000_orders_checked_mark.sql`: добавляет в `purchase_orders` два необязательных поля
`checked_at` (когда) и `checked_by_name` (кто) и разрешает роли `authenticated` обновлять именно их (права на столбцы, как у остальных полей).
Старые заказы не затрагиваются. Отметка снимается кнопкой «Снять отметку» и автоматически — при возврате заказа в черновик.

**Порядок.** `preflight.sql` → применить миграцию (MCP, тремя короткими выражениями) → `postcheck.sql`. Откат — `rollback.sql`.
Фронтенд читает `select('*')`, поэтому до применения миграции он работает как раньше (поля просто пустые), но запись отметки без неё
вернёт ошибку — применять миграцию до слияния PR.
