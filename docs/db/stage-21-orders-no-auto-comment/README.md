# Этап 21 — новые заказы без служебного комментария

**Зачем.** Функция формирования заказов (`generate_procurement_orders_from_snapshot`, версия с 7 аргументами) сама писала в комментарий
заказа и приёмки «Сформировано из планирования закупок». Приёмщику эта фраза ничего не даёт.

**Что делает миграция** `20261023100000_orders_no_auto_comment.sql`: берёт живое определение функции, заменяет два литерала фразы на пустую
строку и пересоздаёт её (права, SECURITY DEFINER и search_path сохраняются). Старые заказы не трогаем: фронт уже считает эту фразу пустым
комментарием (`orderCommentForDisplay`, PR #54).

**Порядок.** `preflight.sql` → применить миграцию (MCP) → `postcheck.sql`. Откат —
`rollback.sql` (точная обратная замена, проверена по хэшу определения).
